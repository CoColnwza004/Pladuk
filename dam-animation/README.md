# ปลาดุกชลเขื่อน — Cinematic 3D animation

แอนิเมชัน 3D แบบ cinematic ความยาว 50 วินาที (1920×1080, 24 fps) ที่เริ่มจากภาพถ่ายโมเดลเขื่อนจริง
ค่อย ๆ ซูมเข้าไปที่เขื่อน แล้วเปลี่ยนจากโมเดลให้กลายเป็นโลก 3D ที่เหมือนมีอยู่จริง พร้อมเสียงธรรมชาติ

ไฟล์วิดีโอ: `../output/pladuk_dam_cinematic.mp4`

## ลำดับภาพ (Timeline)

| เวลา | ภาพ |
|---|---|
| 0–7 s | ภาพถ่ายโมเดลจริง ค่อย ๆ ซูมเข้าไปที่สปิลเวย์ |
| 6.6–10.6 s | โมเดลค่อย ๆ "กลายเป็นของจริง" (dissolve จากกลางเขื่อนออกไป) |
| 10–22 s | โดรนบินผ่านหมู่บ้าน กระชังปลา ทุ่งนา โรงงาน ลานเฮลิคอปเตอร์ แล้วเลี้ยวเข้าหาเขื่อน |
| 22–29 s | บินขึ้นตามสปิลเวย์ 4 ช่อง ผ่านละอองน้ำ ข้ามสันเขื่อน (ถนน รถวิ่ง) |
| 29–43 s | เหนืออ่างเก็บน้ำ: สปิลเวย์ทรงกลม (morning glory), โซลาร์ลอยน้ำ, กังหันลม |
| 43–50 s | มุมสูงเห็นทั้งหุบเขา + ชื่อ "ปลาดุกชลเขื่อน" แล้ว fade out |

เสียง (สังเคราะห์ทั้งหมดด้วย `audio.py`): ลม, น้ำไหลในแม่น้ำ, เสียงน้ำตกจากสปิลเวย์, น้ำกระทบฝั่ง,
นกหลายชนิด (นกกาเหว่า, นกปรอด, นกกางเขนบ้าน, นกกระจอก, นกเขา), จักจั่น/จิ้งหรีด, เสียงกังหันลม และ pad เพลงเบา ๆ

## สร้างใหม่ (Rebuild)

```bash
cd dam-animation
npm install
./build.sh                    # full quality (~2 h on 4 CPU cores, software WebGL)
W=960 H=540 Q=low ./build.sh  # quick draft
```

- `main.js` — ฉาก Three.js ทั้งหมด (ภูมิประเทศ, เขื่อน, น้ำ, อาคาร, ต้นไม้, กล้อง, post-processing)
- `render.cjs` — เปิด Chromium แบบ headless แล้ว render ทีละเฟรม (deterministic)
- `audio.py` — สร้างเสียงธรรมชาติแบบ procedural (numpy/scipy)
- `assets/photo.jpg` — ภาพถ่ายโมเดลที่ใช้ตอนเปิดเรื่อง, `assets/Kanit-*.ttf` — ฟอนต์ Kanit (SIL OFL)
